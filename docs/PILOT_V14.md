# Animal Voices · Community Field Pilot 1.4

## One link. One real test.

**Public share link:** https://animal-voices-os.vercel.app/try.html  
**Independent NVSINO cohort link:** https://animal-voices-os.vercel.app/try.html?from=nvsino

Updated 12 November 2026. No affiliation with NVSINO or Instagram is asserted.

### The experience

1. Visitor opens the link with **no account, installation or editor code**.
2. Picks one of three example comments (taste, ragebait, animal ethics), or types an anonymised custom one.
3. Clicks one primary action to see an editorial moderation recommendation.
4. If appropriate, selects **Warm / Klar / Humor / Neugierig**. On pure ragebait, ignoring is recommended by default; threats are withheld.
5. Previews the draft below the comment without posting to Instagram.
6. Votes **yes / with changes / no**, optionally chooses one improvement reason, and may write a short note.
7. Only by explicit action shares a structured summary through a WhatsApp chooser or copies it. **No automatic collection or central analytics.** The original user's custom comment is not included.

The website root takes ordinary visitors to this pilot, while the previous community pages, Instagram-style simulator, browser companion, Daily/Studio and labs remain accessible by their direct URLs. The NVSINO invitation page's three links also open the unified flow.

### Why the experience is safe for first-time testing

- Static editorial responses can run without contacting an AI vendor.
- No live Instagram integration or real posting occurs in this pilot.
- Contact details, handles and links are refused for custom input; no comment or account content is persisted.
- Source-linked answers include a disclosure and expandable source card. They are **not independently fact-checked in real time**; participants should check sources before publicly reusing text.
- No private API/editor code in the public page.
- The page never posts a feedback message for the visitor. WhatsApp opens a prepared draft and the visitor must choose if, where and whether to send it.
- Intended to promote kind, evidence-aware animal advocacy, not antagonistic dogpiling, shame or manipulative persuasion.

### First cohort: 10 volunteers

Recruit a mixed group where possible, not just enthusiasts; distinguish vegan activists from sceptical participants in analysis. Each volunteer tests **one situation** and optionally a second unfamiliar one.

Ask just three questions, ideally as the app does:

- **Would you actually use/post this reply or follow its no-reply recommendation?** Yes / with changes / no.
- **What is the biggest issue?** Too preachy / too long / missed the question / weak evidence / sounds unnatural.
- **One specific edit that would make this feel more human?** Optional short note.

For manual collection, invite testers to send the voluntary summary to the designated group or researcher. Get permission before moving comments/feedback to any public report; remove identifying information. Pilot feedback is not sent to Animal Voices automatically, so **a link open or generated draft is not a completed research response**.

### Release gate for the next version (targets, not achieved results)

- 10 distinct first-time volunteers have navigated the full flow, not just opened the page.
- 8/10 can reach a recommendation and preview without external instructions.
- At least 7/10 would genuinely use the recommendation or answer with only minor changes; explicitly track non-replies as successes only when justified.
- No serious unsafe or unsupported published suggestions in reviewed cases.
- Document the 3 most frequent reasons for rejection, revise the answers, then rerun a fresh separate set of cases.

These are small-cohort product signals, **not** statistically representative persuasion or animal-welfare outcomes.

### What is not yet validated

- Real logged-in Instagram selectors on physical phones.
- Independent live model generation and primary-source verification.
- User preference outside the development/tester cohort.
- Causal change in people’s attitudes, animal-product purchasing or animal suffering.
- Systematic aggregate feedback or longitudinal retention.

**Next decision:** use volunteer feedback to make the single experience better before restoring more features to its public path.
