# Animal Voices v0.9 — independent end-to-end QA (2026-11-08)

**Result:** 38/38 automated tests and 15/15 additional Chromium interaction checks passed after fixes. [GitHub CI](https://github.com/mikelninh/animal-voices-os/actions/runs/42518518259). Production deployment `dpl_CQonCHsQPzXf2pCugzE545wnHPW2` is READY.

## What was tested

- Known topic: Instagram comment → recommendation → inspect evidence → editable response → mandatory source-open and reviewer checks → approval → copy with citations → explicit self-reported posting → change reply invalidates approval.
- Context traps: quoted debunk, negated claim, bait, clear threats, pregnancy and minor nutrition questions, unsupported topic.
- Share fallback: receiving an Instagram post URL alone does **not** pretend the comment text was shared.
- Content ideas: stored examples anonymize handles and email addresses.
- Responsive browser UI: 360, 390, 768, 1440 px, no horizontal overflow or JS exceptions.
- POST Share Target: mocked IndexedDB/service-worker contract tests; no live OS share-sheet test.

## New defects found and fixed

1. Threats containing topical keywords such as "schwach" could previously be classified as nutrition claims. Strengthened severity-first threat detection in `engine.js` and `triage.js`.
2. A 14-year-old asking for B12 dosage could previously be treated as a routine nutrition question. Explicit underage nutrition queries now abstain and require human/expert review.
3. Incremented `sw.js` offline cache identifier from `animal-voices-v09-shell-1` to `-2` to deliver these safety changes to installed PWAs.
4. Repaired Vercel output directory configuration (`.`) after failed initial deployments.

Added seven permanent regression tests under `tests/safety_edge.test.mjs`. These tests are evidence of *known-case* coverage, not proof that all threats and medical situations will be recognized.

## What was not tested

- A real Android device's Instagram → Share-sheet → installed PWA handshake.
- Opening the actual scientific documents inside the restricted Chromium test environment (only URL and link-open event were tested).
- Sending real Instagram replies, API-authorized Instagram comment ingestion or live model calls.
- Scientific source accuracy in full text, external peer review, causal effect on minds or animals.
- Browser navigation to real internet targets is blocked by administrator policy; E2E uses the actual shipped frontend in Chromium with outbound navigation and clipboard simulated. Public site and production tree were separately confirmed using provider tools.

**Next acceptance criterion:** Real-device Android share-target smoke test + one anonymized real comment with manually checked primary source and consented follow-up. No auto-posting.
