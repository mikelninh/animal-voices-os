# Animal Voices OS

**For animals. With humans.**

An evidence-led, compassionate editorial workspace for animal advocacy: collect comments, check source-backed claims, write kind replies, approve manually, and test original content.

Production website: https://animal-voices-os.vercel.app

The workflow does not automatically post on Instagram or X. Scientific sources are editorial references, not a live-verified or externally peer-reviewed certification.

This repository is the source of truth for the upcoming v0.6 high-fidelity UI release.
